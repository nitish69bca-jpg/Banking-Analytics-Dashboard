# Banking Analytics Dashboard

## About the Project

This project is a Power BI dashboard created using banking data. The main goal was to understand customer activity and get a clear view of loans, deposits, and other important banking metrics.

I built the dashboard with multiple pages so that the data can be explored from different angles instead of looking at everything in one place.

## Tools Used

- Power BI
- Power Query
- DAX
- Python / Jupyter Notebook
- CSV dataset

## What I Analyzed

The dashboard covers the following areas:

- Customer count and customer-related metrics
- Total loan and bank loan
- Business lending
- Total deposits and bank deposits
- Saving and checking account amounts
- Credit card amount
- Foreign currency amount
- Banking relationship
- Gender
- Income bands
- Nationality
- Customer engagement timeframe

## Dashboard Pages

### Home

The Home page gives a quick overview of the main banking metrics. It also includes filters that can be used to view the data based on different selections.

### Loan Analysis

This page focuses on lending-related data. I used different charts to compare bank loans across banking relationships, income bands, nationalities, and customer engagement timeframes.

### Deposit Analysis

This page focuses on deposits and account-related information. It shows total deposits, bank deposits, saving accounts, checking accounts, foreign currency amounts, and their distribution across different customer groups.

### Summary

The Summary page brings the main KPIs together. It is useful for getting a quick understanding of the overall banking performance without going through each analysis page separately.

## Dashboard Features

- Interactive slicers and filters
- KPI cards
- Bar charts
- Donut chart
- Treemap
- Page navigation
- Customer segmentation
- Loan and deposit analysis

## Key Insights

Some of the main things I looked at through the dashboard were:

- How loans are distributed across different customer groups.
- How deposits vary across income bands and nationalities.
- The contribution of bank loans and business lending to total lending.
- Differences in customer activity based on engagement timeframe.
- Overall loan, deposit, and customer-related KPIs.

## How to Run the Project

1. Download or clone this repository.
2. Open `Banking Dashboard.pbix` using Power BI Desktop.
3. If required, update the dataset path in Power BI.
4. Refresh the data.
5. Use the filters and navigation buttons to explore the dashboard.
